# 文件安全策略

状态：**PASS（第五部分所列 fixture 范围内）**。`app.security.files` 是试卷、通用上传和学生作业的统一内容检查入口。

已实施：

- 单文件和批次总大小限制；上传按上限加 1 字节读取，避免无界读取。
- 扩展名、声明 MIME 和魔数三者一致；假 PDF/PNG/JPEG 被拒绝。
- PDF 使用严格解析，拒绝损坏、加密、空页和超过 `RECOGNITION_MAX_PDF_PAGES` 的文件。
- 图片在完整解码前检查像素数，捕获 Pillow 解压炸弹、损坏图片和异常 EXIF 解码错误。
- DOCX/XLSX 校验真实 ZIP 结构、条目数、总展开大小、单条目压缩比和路径穿越；拒绝宏及外部关系。
- 学生 XLSX 拒绝公式；CSV/表格字段拒绝公式注入前缀。报告输出继续执行公式转义。
- 文件名只保留 basename，限制 255 字符并拒绝控制字符；对象键使用 owner UUID 与随机 UUID，不使用原文件名。
- 学生作业整批先验证后写入；存储异常回滚数据库并返回明确错误。
- 系统不接受用户 ZIP；批量 PDF ZIP 只由 Worker 生成，不新增 ZIP 上传面。
- 拒绝文件不会进入 ready 状态，日志不记录文件正文或二进制。

第五部分现覆盖加密/截断/损坏/零页/空白/超页 PDF，假图/截断/超像素图片，
Office 宏、外链、损坏 XML、缺核心文件、路径穿越、条目数和压缩比，以及 CSV/XLSX
公式注入。批次首/中/末非法、重复校验值、存储和数据库失败均验证零半成品；真实
MinIO 短期 URL 到期与重签通过；共 41/41 个运行时结构 fixture，本轮孤儿增量为 0。
详见 `FILE-SECURITY-VERIFICATION.md`。

默认限制见 `.env.example`。大型恶意 fixture 不进入仓库；测试应运行时生成小型结构文件。
本结论不是外部渗透、真实恶意软件执行、无限解析器模糊测试或生产安全认证；Redis/MinIO
故障恢复、MinIO 备份恢复、生产容量和运维仍未完成。
