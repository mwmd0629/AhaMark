# AhaMark 统一产品能力声明

适用版本：`0.1.0`；验收等级：**C（内部演示或开发测试）**。任何单独截图、标题、销售材料或口头演示也必须遵守本表，不能依赖另一页的小字补救。

| 主题 | 可以说 | 必须附带限制才能说 | 禁止说 |
|---|---|---|---|
| AI 批改 | “AI/规则提供初批建议，教师把关并形成最终成绩。” | 使用“AI 批改”作栏目名时，必须同屏说明当前主要是规则评分、主观题真实 AI unavailable、低置信/异常必须人工复核。 | “AI 直接决定最终成绩”“无需教师复核”。 |
| 自动批改 | “明确答案的客观题可按确定性规则自动比对并给出建议分。” | 仅可用于 single/multiple choice、true/false、fill blank 的规范化精确匹配；单位、精度、歧义和异常进入人工复核。 | “所有题型自动批改”“全自动完成评分”。 |
| 主观题评分 | “系统支持教师人工评分、复核、评语与修改追踪。” | 可以说已预留统一 Provider 接口，但必须紧接“真实主观题 AI Provider 当前 unavailable”。 | “AI 主观题评分已可用”“主观题准确率达到某数值”“Fake Provider 是产品能力”。 |
| OCR | “提供本地 RapidOCR 印刷体文字识别，输出文本、坐标和置信度，并支持人工修正。” | 必须说明验证样本很小、未计算 CER/WER、低置信和异常需人工复核；DOCX 转换依赖外部 LibreOffice。 | “高准确率 OCR”“适用于所有试卷/答卷”“OCR 结果可直接评分无需复核”。 |
| 公式识别 | “公式识别 Provider 当前 unavailable；普通数学字符可能仅作为普通文字保留。” | 不应把识别到 `+ - × ÷ =` 等字符称为公式识别。 | “支持公式 OCR”“可靠生成 LaTeX”。 |
| 手写识别 | “手写数学尚未充分验证。” | 只有在明确标为实验性、无准确率承诺且要求人工复核时，才可展示有限现象。 | “支持手写作业识别”“手写识别已可用于真实教学”。 |
| 最终成绩 | “教师完成逐题复核并 finalize 后，系统从最新 complete ScoreSnapshot 读取正式成绩。” | 必须说明无 complete Snapshot 是未完成，不是零分；AI 建议和 GradingResult 不是最终成绩。 | “模型分就是最终成绩”“临时复核结果可直接统计”。 |
| 成绩发布 | “GradeRelease 固定教师确认的一组具体成绩快照。” | 必须说明 `released` 只表示教师确认发布数据。 | “成绩已发送/送达学生”“学生端已上线”“已完成通知”。 |
| 学情分析 | “基于固定 GradeRelease 生成版本化统计、下钻和趋势。” | 必须说明未完成学生不计入分母、主观题不显示正确率、知识点规则和样本口径透明。 | “AI 自动发现学习规律”“证明教学效果”“未交按零分统计”。 |
| 教学建议 | “提供基于固定 AnalyticsSnapshot 指标的规则型教学建议，教师可编辑、确认、重新生成和失效。” | 使用“智能建议”时必须同屏标记 `rule_based` 并解释规则来源。 | “大模型深度教学诊断”“AI 自主制定教学策略”。 |
| 生产可用 | “当前是等级 C 的内部演示/开发测试版本。” | 可以描述已实现的局部安全、代理、备份或性能验证，但必须列明未完成项。 | “生产就绪”“企业级安全”“可公网部署”。 |
| 真实教学可用 | “当前不适合真实教学试点。” | 不得以“受控试点”“小范围试用”绕过真实数据禁令。 | “可用于真实班级/学生”“已具备教学落地条件”。 |

## 必须统一附带的总声明

> AhaMark 当前为 C 级内部演示/开发测试版本，仅使用合成数据。AI/规则结果是教师复核前的建议，不能直接成为最终成绩；真实主观题 AI、公式识别和经充分验证的手写数学识别当前不可用。成绩发布表示教师确认固定数据，不表示学生已收到。教学建议为规则型，不是大模型自主诊断。

## 已知界面措辞风险

当前导航与状态组件存在“AI 批改”“AI 批改中”等短标签。它们只有在上下文同时呈现上述限制时才合规；脱离上下文的截图或引用禁止使用。由于第一部分禁止修改前端，本次只建立统一声明和风险记录。
